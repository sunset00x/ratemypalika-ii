# Rate My Palika  🇳🇵

**Rate My Palika** is a lightweight, open-source civic technology platform designed to improve transparency, accountability, and citizen feedback across local government bodies (*Palikas*) in Nepal.

The platform allows citizens to rate and evaluate municipal performance across key public indicators—including road infrastructure, waste management, public health services, bureaucratic efficiency, and anti-corruption transparency—at both the Palika and Ward levels.

---

## 🚀 Key Features

* **Ward-Level Evaluation:** Pinpoint citizen evaluations down to specific ward administrative units.
* **5-Point Civic Metrics:** Quantitative scoring across 5 core indicators:
  1. **Roads & Infrastructure**
  2. **Waste Management & Cleanliness**
  3. **Local Health Services**
  4. **Bureaucratic & Administrative Efficiency**
  5. **Transparency & Anti-Corruption**
* **Real-time Performance Leaderboard:** Dynamic aggregation of municipal ratings providing public visibility and comparative rankings.
* **Basic IP Rate-Limiting:** Simple protection mechanisms against automated form spam and multiple reviews within 24 hours per IP.
* **Native & Secure PHP Stack:** Built using native PHP with PDO prepared statements for secure, SQL-injection-proof database operations.

---

## 🛠️ Tech Stack & Requirements

* **Language:** PHP 8.0+
* **Database:** MySQL 8.0+ / MariaDB 10.4+
* **Database Driver:** PHP Data Objects (PDO)
* **Frontend:** Plain HTML5, CSS3, UTF-8
